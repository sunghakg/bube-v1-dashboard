# Global M2 → SOXX 78일 선행 가설 검증

블로그 주장(지텐의 퇴근 후 투자 스쿨):

> Global M2를 약 78일 선행시키면 2025년 이후 SOXX와 거의 똑같이 움직인다.
> 돈이 풀리면 채권→금→주식 순으로 흘러들어 시차가 생기기 때문이다.
> 지금 M2가 하락 전환이면 7월~3분기 큰 하락이 올 수 있다.

이 폴더의 `verify_m2_lead.py` 는 그 주장을 데이터로 검증한다.
차트를 눈으로 겹쳐 보는 것은 증명이 아니므로, 아래 4가지 검정 + 플라시보로 나눈다.

| 검정 | 질문 | 통과 기준 |
|---|---|---|
| T1 lag 스캔 | 상관 최대화 선행일수가 정말 ~78일인가 | k* ∈ 78±21일 |
| T2 안정성 | 그 선행일수가 2023–24 구간에서도 같은가 | 구간 간 차이 ≤21일 |
| T3 변화율 상관 | 공통 추세를 제거해도 상관이 남는가 | 4주 변화율 corr ≥ 0.3 |
| T4 예측력 | M2 변화가 SOXX 이후 4주 수익률을 맞히는가 | t>2 & 적중률>60% |
| P 플라시보 | 무관한 랜덤워크도 시프트 고르면 corr 0.9가 나오는가 | 관측 corr가 플라시보 분포 상위에 있어야 의미 |

핵심 논점: 우상향하는 두 시계열은 **레벨 상관이 거의 항상 높게 나온다**
(허구적 회귀, spurious regression). 주장이 진짜이려면 T3·T4가 통과해야 한다.

## 실행

```bash
cd analysis/m2_soxx_lead
python verify_m2_lead.py --plot                # US+EU 합성 M2
python verify_m2_lead.py --m2-csv m2_tv.csv    # TradingView 내보내기(정확 재현)
```

- 기본 모드는 FRED(US M2 주간) + ECB(EU M2) + yfinance(SOXX, EURUSD)만 사용
  (API 키 불필요). 중국·일본 M2는 무키 공개 API가 없어 제외되므로,
  차트의 인디케이터를 정확히 재현하려면 TradingView에서
  "M2 Global Liquidity Index" 데이터를 CSV로 내보내 `--m2-csv` 로 전달.
- 네트워크가 열린 환경(로컬/트레이더 박스)에서 실행할 것.
  Claude 원격 세션에서는 시장 데이터 호스트가 차단됨.

## 참고 (외부 검증 사례 — BTC에 대한 동일 주장)

- 동일한 "Global M2 + N일 시프트" 기법은 BTC에서 유행했고(78~108일 등),
  최적 시프트가 기간마다 흔들리고(과적합), 2025-09월에는 커플링이 깨졌다는
  분석이 다수. 시프트 일수는 자유 파라미터라 사후적으로 잘 맞는 값을
  고르면 항상 "맞아 보인다".
